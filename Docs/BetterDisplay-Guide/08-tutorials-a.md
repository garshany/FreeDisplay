### 2. Native flexible scaling and virtual alternatives — https://betterdisplay.pro/guide/tutorials/fully-scalable-hidpi-desktop/ ; https://betterdisplay.pro/guide/tutorials/fully-scalable-hidpi-desktop/assets/fully-scalable-hidpi-desktop-scaling.mp4/

Intel supports eligible native overrides but not this external activation shortcut.
  - The app-menu resolution slider chooses closer-spaced HiDPI desktop sizes. Smaller logical dimensions enlarge UI; backing pixels and panel pixels are different. Its 100% origin is the default desktop resolution. More system options can edit that default independently.
  - In More system options, compare reported native resolution with the panel specification. Enable native-panel pixel editing only to correct actual physical width/height, then Apply and reactivate/reboot. The illustrated 5120 × 2880 is a model example, not a universal default.
  - Overview → Advanced Display Settings has an over-8K range option, initially off; 8K backing corresponds to 4K HiDPI desktop. It does not bypass GPU/allocation limits, can destabilize apps, and requires reapplying flexible scaling after changing it.

Enable full-screen streaming and landscape/no rotation; for mirroring, disable streaming and enable virtual mirroring instead. Grant capture permission and reopen the sheet when needed. The matched virtual desktop connects and presents on the selected target. Work on and resize the virtual source, not the physical receiver.
  - Mirroring shares a desktop; streaming retains independent source/receiver desktops and supports transforms. Command-click the streamed picture warps the pointer to the source. Wrong-direction mirrors must be stopped and reconfigured from virtual source to physical receiver; set the intended main display and arrange accessible desktop edges.

### 7. Complete HiDPI modes, refresh rates and protection — https://betterdisplay.pro/guide/tutorials/hidpi-and-high-refresh-rate/

- **BetterDisplay behaviour** (Free ordinary selection/reporting; Pro overrides/HDR/protection/group features):

Same logical size at a different rate can be LoDPI; a high rate elsewhere is not proof the desired combination exists. The resolution slider also selects a complete mode.

Blank/green/distorted output requires restoring the recorded complete mode from recovery.
  - Option-opening Refresh Rate reveals measured, reported-actual and nominal rates and broadens the ordinary list. These are software timing readings, not physical panel measurements or game FPS.
